# Enclosure Design

Physical enclosure for the ESP32 NeoTrellis Box.

## Directory Structure

```
enclosure/
├── 3d-print/     STL and STEP files for 3D printing
└── laser-cut/    DXF files for laser-cut acrylic
```

## Design Requirements

- Accommodate PCB and NeoTrellis keypad
- USB connector access
- Ventilation for heat dissipation
- Mounting options: wall-mount, desktop stand
- Materials: 3D-printed PLA/PETG or laser-cut acrylic

## Tools

- FreeCAD, Fusion 360, or OpenSCAD for 3D modelling
- Inkscape or LibreCAD for laser-cut DXF files
