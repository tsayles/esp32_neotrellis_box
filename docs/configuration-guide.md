# Configuration Guide

*To be completed during firmware development.*

## WiFi Setup

1. On first boot the device creates an access point
   named `NeoTrellis-XXXX`.
2. Connect to the AP and navigate to `192.168.4.1`.
3. Enter your WiFi credentials and save.

## MQTT Broker

Configure the MQTT broker address, port, username,
and password through the web interface or by editing
the configuration JSON stored in LittleFS.
