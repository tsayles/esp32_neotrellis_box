# Assembly Guide

*To be completed during hardware prototyping phase.*

## Prerequisites

- Assembled PCB (or prototype breadboard)
- ESP32-C3 Super Mini development board
- Adafruit NeoTrellis 4x4 keypad
- USB cable for power and programming
- Enclosure (optional)

## Steps

1. Mount the ESP32 module onto the PCB
2. Connect the NeoTrellis via the I2C header
3. Verify power supply connections
4. Flash firmware (see [firmware/README.md](../firmware/README.md))
5. Install into enclosure
